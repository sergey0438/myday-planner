# MyDay Planner

Личный планировщик дел с голосовым вводом. Работает на iPhone, iPad и компьютере как PWA,
синхронизирует задачи через Supabase и продолжает работать без интернета.

**Приложение:** https://sergey0438.github.io/myday-planner/

## Возможности

- Экран «Сегодня»: дата, приветствие, прогресс, ближайшее дело, расписание по времени, просроченные задачи.
- Голосовое планирование: диктовка нескольких дел одной фразой (русский и украинский), локальный разбор дат,
  времени, повторений и места, предпросмотр с подсветкой сомнительных полей, сохранение после подтверждения.
- Ручное создание и редактирование: название, описание, дата, время начала и окончания, категория, приоритет,
  место, повторение, подзадачи; дублирование, перенос, удаление (серии или одного повторения), выполнение и возврат.
- Календарь: день (по часам), неделя, месяц; перетаскивание задач между днями и по часам, фильтр по категориям.
- Входящие (задачи без даты), избранное, архив выполненных, поиск, статистика.
- Категории со своими цветами, создание своих категорий.
- Светлая и тёмная темы, русский и украинский интерфейс, часовой пояс (по умолчанию Europe/Kyiv), первый день недели.
- Резервные копии: экспорт JSON и CSV, импорт JSON.
- Синхронизация: локальная база IndexedDB, очередь изменений, Realtime, слияние одновременных правок,
  явный выбор версии при конфликте (без тихой перезаписи).

## Архитектура

| Слой | Технологии |
| --- | --- |
| Интерфейс | React 18, TypeScript, Vite, Tailwind CSS, Radix UI, Lucide |
| Разбор речи | `src/nlp/parser.ts` — собственные правила RU/UK, работает полностью на устройстве |
| Распознавание речи | Web Speech API (Safari iOS 14.5+, Chrome, Edge); резерв — системная диктовка клавиатуры |
| Локальные данные | IndexedDB (`idb`), очередь изменений `outbox` |
| Облако | Supabase Free: Postgres, Auth (email+пароль), Row Level Security, Realtime |
| Синхронизация | `src/sync/engine.ts` — версии строк, 3-стороннее слияние, конфликты |
| PWA | `vite-plugin-pwa` (Workbox), manifest, иконки, офлайн-кеш, запрос на обновление |
| Публикация | GitHub Actions → GitHub Pages |

## База данных

SQL-схема: [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql).
Её нужно один раз выполнить в Supabase → SQL Editor. Схема создаёт таблицы `tasks`, `categories`,
`user_settings`, политики RLS (каждая строка доступна только владельцу), триггер версий и запрет
регистрации второго аккаунта.

Ключ `VITE_SUPABASE_ANON_KEY` в `.env.production` — публикуемый (publishable) ключ Supabase: он
предназначен для браузера и сам по себе не даёт доступа к данным, их защищают RLS-политики.
Секретные ключи (`service_role`, пароль БД) в репозитории не хранятся.

## Разработка

```bash
npm ci
npm run dev        # локальный сервер
npm test           # unit-тесты: парсер, синхронизация, SQL-схема на PGlite
npm run test:e2e   # Playwright: сценарии в браузере (iPhone/iPad), с имитацией Supabase
npm run build
```

Любой push в `main` запускает тесты и публикует сайт на GitHub Pages.
